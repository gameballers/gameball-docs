<Update label="November 19 2026" description="Faster Leaderboard API" tags={["API"]}>

## Leaderboard API: Millisecond Rankings and Net Totals

The [Customer Leaderboard API](/api-reference/leaderboard/customer-leaderboard) now returns rankings in milliseconds, with weekly, daily, and custom date ranges. Rankings use net totals, with refunds and cancellations taken off the period of the original purchase. It ranks up to 1,000 customers by default, and up to 10,000 when you need deeper rankings. Existing periods and options are unchanged.

</Update>

<Update label="November 17 2026" description="Customer webhook and Cashback Settings" tags={["API", "Webhooks"]}>

## Customer Profile Webhook: Status, Deletion and Referral Data

The customer profile webhook now includes `status`, `is_deleted`, `referred_by_customer_id`, `is_referral_activated`, `total_referrals`, `active_referrals`, and `pending_referrals`. A final webhook with `is_deleted` set to `true` is sent when a customer is deleted. These fields are available on webhook version 4. Earlier versions keep their existing payload. See [Customer Profile Updates](/api-reference/webhooks/webhook-topics/profile-updates).

***

## Cashback Settings API: Eligibility, Custom Rules and Multiplier Campaigns

The [Cashback Settings API](/api-reference/configurations/reward-configurations/cashback-settings) now returns the default rule's eligibility, `customCashbackRules`, and `pointsMultiplierCampaigns`, so you can calculate what an order will earn before checkout.

</Update>
