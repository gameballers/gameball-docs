---
title: "Calculate Order Cashback"
description: "Calculate expected cashback points for an order (no reward applied)."
openapi: 'POST /api/v4.0/integrations/orders/cashback'
languages: ["curl", "javascript", "python", "csharp", "php", "go", "java", "ruby"]
---

Calculate the cashback points to be rewarded for a specific order. This estimates rewards based on your configured rules and eligibility; it does not perform any reward.

To also preview `place_order` campaign rewards (points and coupons) in the same call, use [Preview Order Rewards](/api-reference/order/preview-order-rewards).

<Info>
Security: Provide `apikey` header.
</Info>
