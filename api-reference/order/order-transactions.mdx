---
title: "Order Transactions"
description: "Retrieve reward, refund, and redemption transactions for a specific order."
openapi: 'GET /api/v4.0/integrations/orders/{orderId}/transactions'
languages: ["curl", "javascript", "python", "csharp", "php", "go", "java", "ruby"]
---

Retrieve transactional details linked to an order (rewards, refunds, redemptions).

To retrieve transactions for many orders at once, use the [Order Transactions Batch Job](/api-reference/batches/batch-creation/order-transactions).

<Info>
Security: Provide both `apikey` and `secretkey` headers.
</Info>
