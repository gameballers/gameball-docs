### Streak campaign rewards

For campaigns with `type` set to `Streak`, the response includes the interval used to count the streak and the step range for every reward.

`streakIntervalUnit` is `Day`, `Week`, or `Month`. Each reward's `startStep` and `endStep` are measured in that unit: day 7 of a daily streak, week 7 of a weekly streak, or month 7 of a monthly streak.

| Field | Description |
|---|---|
| `streakIntervalUnit` | The unit used to count streak steps. `Day`, `Week`, or `Month`. Returned only for streak campaigns. |
| `rewards[].order` | The display order of this reward tier, starting at 1. |
| `rewards[].startStep` | The first step (in `streakIntervalUnit`) at which this reward applies. |
| `rewards[].endStep` | The last step at which this reward applies. Omitted on the final open-ended tier, which applies from `startStep` onward. |

Tiers with `walletReward` of `0` are progress ranges with no points. Use them to render the full streak timeline, then highlight the tiers that grant points or a coupon.

In this daily streak (`streakIntervalUnit: "Day"`):

| Steps | Reward |
|---|---|
| Days 1–6 | No points |
| Day 7 | 10 points |
| Days 8–13 | No points |
| Day 14 | 20 points |
| Days 15–20 | No points |
| Day 21 | 30 points |
| Days 22–29 | No points |
| Day 30 onward | 100 points |

The last reward has `startStep` 30 and no `endStep`, so it applies from day 30 onward.

To read a customer's position against these steps, call [Customer Campaigns Progress](/api-reference/customers/progress/get-customer-campaigns-progress) with `campaignId`.
