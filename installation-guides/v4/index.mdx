## What's New in SDK v4

<CardGroup cols={2}>
<Card title="In-App Messaging" icon="comment-dots">
Display the slide-up, modal, and full-screen campaigns you create in the Gameball dashboard
</Card>

<Card title="Purchase Logging" icon="cart-shopping">
Send purchases with `logPurchase` so campaigns can target and filter on them
</Card>

<Card title="New Platform Minimums" icon="mobile">
iOS 15.0 and Android API 24 (Android 7.0) are now the minimum supported versions
</Card>

<Card title="Compatible with v3" icon="arrows-rotate">
Every v3 call works unchanged, so upgrading needs no code changes
</Card>
</CardGroup>

## What You'll Learn

Each platform guide covers the essential integration steps:

- **Getting Started** - Install the SDK and set up dependencies
- **Initialize SDK** - Configure the SDK with the builder pattern
- **Initialize Customer Profile** - Register customers and show the profile widget
- **Track Customer Events** - Send customer actions and behaviors to Gameball
- **Track Referrals** - Implement referral tracking
- **In-App Messaging** - Display dashboard in-app campaigns in your app
- **Go-Live Checklist** - Ensure everything is ready for production
- **Migration Notes** - Upgrade from v3 to v4, or migrate from v2

## Prerequisites

Before starting your integration, make sure you have:

- A Gameball account with API credentials
- Your application's development environment set up
- Basic understanding of your chosen platform's development workflow

<Tip>
SDK v4.0.0 is available for **Android**, **Flutter**, **React Native**, and **iOS**. The Web SDK with in-app messaging is not released yet.
</Tip>
