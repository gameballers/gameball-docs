# Gameball React Native SDK — v4.0.0

This documentation is tailored to **Gameball React Native SDK v4.0.0**. Use these pages as a versioned SDK reference for teams embedding Gameball into their React Native applications.

<Info>
SDK v4.0.0 adds in-app messaging and purchase logging, and raises the minimum versions to iOS 15.0 and Android API 24. Every v3.x call keeps its signature and behavior.
</Info>

## Requirements

- **React Native**: 0.70+
- **Node.js**: 18+
- **TypeScript**: 4.0+ (optional but recommended)
- **iOS**: iOS 15.0+
- **Android**: API level 24+ (Android 7.0)
