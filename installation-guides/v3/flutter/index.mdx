# Gameball Flutter SDK — v4.0.0

This documentation is tailored to **Gameball Flutter SDK v4.0.0**. Use these pages as a versioned SDK reference for teams embedding Gameball into their Flutter applications.

<Info>
  SDK v4.0.0 adds in-app messaging and purchase logging, and raises the minimum versions to iOS 15.0 and Android API 24. Every v3.x call keeps its signature and behavior.
</Info>

## Requirements

- **Minimum Flutter Version**: 1.17.0
- **Dart**: 3.4.4+
- **Android**: API level 24+ (Android 7.0)
- **iOS**: iOS 15.0+

<Note>
  v4.0.0 raised the Android and iOS minimums. See [Migration Notes](/installation-guides/v3/flutter/migration-notes) to upgrade from v3.
</Note>
