**Available for all Gameball customers**

The **Gameball MCP Server** lets an AI assistant work with your Gameball account on your behalf. It uses the [Model Context Protocol (MCP)](https://modelcontextprotocol.io), an open standard supported by assistants such as Claude, ChatGPT, Gemini, and Cursor, so you can look up customers, adjust your program, and build campaigns in a conversation instead of clicking through the dashboard.

```
https://mcp-v2.gameball.co/v1.0/mcp
```

---

## Why Connect an AI Assistant to Gameball?

* **Work in plain language**: Ask "How many points does this customer have?" or "Create a tier for customers who spend over 500" and the assistant runs the matching Gameball actions.
* **Stay in control of access**: You sign in with your own Gameball account and choose exactly which areas the assistant can read and which it can change.
* **Use the assistant you already have**: Any AI app that supports remote MCP servers can connect. No API keys to copy and no code to write.

---

## How to Connect Your AI Assistant

Connecting takes two parts: add the Gameball server in your AI app, then sign in and choose what the assistant can access. Find your app below for the first part.

<Note>
AI apps rename their menus often. If a label below does not match what you see, look for the option to add a custom MCP server or custom connector.
</Note>

### Claude (Web and Desktop)

1. Open **Customize > Connectors**.
2. Select **Add**, then **Add custom connector**.
3. Enter a name, such as `Gameball`, and the server URL `https://mcp-v2.gameball.co/v1.0/mcp`.
4. Click **Continue**, then **Add**, then **Connect**.

Custom connectors are available on every Claude plan. The Free plan allows one custom connector. On Team and Enterprise plans, an Owner adds the connector first under **Organization settings > Connectors**.

### ChatGPT

1. On ChatGPT web, go to **Plugins**, select the plus button, then **Add custom MCP server**.
2. Enter a name, such as `Gameball`.
3. Under **Connection**, enter the server URL `https://mcp-v2.gameball.co/v1.0/mcp`.
4. Select the checkbox to confirm you want to continue, then click **Create as a plugin**.

<Note>
**Plan and Platform Limits**: ChatGPT supports custom MCP servers on the web only, not in the mobile apps. Business, Enterprise, and Edu workspaces get full access, where admins and owners create the connection. Pro accounts can connect with read access only, so actions that change your program are not available there.
</Note>

### Gemini

1. In the Gemini web app, open **Settings > Connected Apps**.
2. Add a custom app and enter the server URL `https://mcp-v2.gameball.co/v1.0/mcp`.

Custom apps in Gemini are not available for every account, language, or region. If you do not see the option, use one of the other assistants listed here.

### Cursor

Add Gameball to your `~/.cursor/mcp.json` file, then open **Customize** in the Cursor sidebar and connect the server:

```json
{
  "mcpServers": {
    "gameball": {
      "url": "https://mcp-v2.gameball.co/v1.0/mcp"
    }
  }
}
```

### VS Code (GitHub Copilot)

1. Open the Command Palette and run **MCP: Add Server**.
2. Choose **HTTP (HTTP or Server-Sent Events)**.
3. Enter the server URL `https://mcp-v2.gameball.co/v1.0/mcp` and a server ID, such as `gameball`.

### Claude Code

Run this command, then run `/mcp` and choose to authenticate the `gameball` server:

```bash
claude mcp add --transport http gameball https://mcp-v2.gameball.co/v1.0/mcp
```

### Other AI Apps

Any app that supports remote MCP servers with sign-in can connect. Add a remote MCP server and enter the server URL `https://mcp-v2.gameball.co/v1.0/mcp`.

## Sign In and Choose Permissions

<Steps>
  <Step title="Sign In to Gameball">
    When you connect the server, a browser window opens the Gameball sign-in page. Log in with the same account you use for the Gameball dashboard.
  </Step>
  <Step title="Choose What the Assistant Can Access">
    Review the list of permissions and select the ones you want to grant. Each area of your account has a separate read permission and write permission, so you can let the assistant view an area without letting it make changes.
  </Step>
  <Step title="Start Asking">
    Return to your assistant and ask it what it can do with Gameball. It only sees the actions that match the permissions you granted.
  </Step>
</Steps>

<Tip>
Start with read permissions only. Add write permissions later, once you are comfortable with how the assistant works with your account.
</Tip>

## What Your Assistant Can Do

| Area | Examples |
|---|---|
| **Customers** | Look up a customer, review their activity, add or deduct points, update profile details, assign or remove tags, and update points or tags in bulk from a CSV file |
| **Earning rules** | Review and change how customers earn points, including earning rules and exceptions |
| **Redemption options** | Create, edit, activate, or remove the options customers redeem their points for |
| **VIP tiers** | Create tiers, set thresholds and rewards, and adjust tier settings |
| **Reward campaigns** | Create and edit campaigns, set their audience, schedule, and rewards, and turn them on or off |
| **Communication campaigns** | Create email, SMS, and push campaigns, set their audience and content, schedule them, and turn them on or off |
| **Program setup** | Manage tags, customer attributes, events, merchants, and branches |

---

## Important Notes

<Warning>
**Changes Are Live**: Actions taken with a write permission apply to your real program and customers, just like changes you make in the dashboard. Grant write permissions only for the areas you want the assistant to manage, and review what it plans to do before you confirm.
</Warning>

<Note>
**Signing In Again**: Your assistant stays connected while you keep using it. If you do not use the connection for 30 days, sign in again to reconnect.
</Note>

## Common Questions

<AccordionGroup>
  <Accordion title="Which AI assistants can connect to Gameball?">
    Any assistant that supports remote MCP servers with sign-in. This page has steps for Claude, ChatGPT, Gemini, Cursor, VS Code with GitHub Copilot, and Claude Code.
  </Accordion>
  <Accordion title="Does the assistant see my Gameball password?">
    No. You sign in on the Gameball sign-in page, not inside the assistant. The assistant only receives access to the permissions you approve.
  </Accordion>
  <Accordion title="Can I change the permissions later?">
    Yes. Disconnect Gameball in your assistant and connect again, then select a different set of permissions when you sign in.
  </Accordion>
  <Accordion title="Why does the assistant say it cannot do something?">
    The action needs a permission you did not grant. Reconnect and select the read or write permission for that area.
  </Accordion>
</AccordionGroup>
